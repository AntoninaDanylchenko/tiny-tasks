##  TidyTask

**TidyTask** — це мінімалістичний To-Do List для щоденних завдань.  
Створюй, позначай виконане й підтримуй порядок у своїх справах. 🪶

---

###  Встановлення

1️⃣ Клонуй репозиторій:
```bash
git clone https://github.com/AntoninaDanylchenko/tidytask.git
```

2️⃣ Створи та активуй віртуальне середовище:
```bash
python -m venv .venv
.venv\Scripts\activate
```

3️⃣ Встанови залежності:
```bash
pip install -r requirements.txt
```

4️⃣ Застосуй міграції та запусти сервер:
```bash
python manage.py migrate
python manage.py runserver
```

---

###  Функціонал

- Додавання нових завдань  
- Позначення завдань як виконаних  
- Видалення непотрібних  
- Простий і чистий інтерфейс
